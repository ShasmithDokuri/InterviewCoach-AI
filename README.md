# InterviewCoach AI

AI-powered interview preparation platform that helps candidates practice technical, behavioral, resume-based, and mock interview questions.

## 🚀 Live Demo

[Open InterviewCoach AI](https://interviewcoach-ai-qaxx.onrender.com)

## ✨ Features

- Resume PDF analysis
- Personalized interview questions
- Technical interview preparation
- Resume and project-based questions
- Behavioral interview preparation
- Mock interview mode
- AI-generated example answers
- Answer evaluation and feedback
- Speech recognition
- Voice recording and playback
- Interview difficulty based on interview type

## 🤖 AI-Powered Interview Preparation

InterviewCoach AI analyzes the candidate's resume, job description, projects, and interview type to provide personalized interview preparation and feedback.

## 🛠 Tech Stack

- JavaScript
- Node.js
- Express.js
- HTML
- CSS
- PDF.js
- Web Speech API
- AI / LLM APIs
- REST APIs
